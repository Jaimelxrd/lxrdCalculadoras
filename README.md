# lxrdCalculadoras

Um site simples e funcional com **três calculadoras online**:

1. **Calculadora de IMC** – Calcula o Índice de Massa Corporal e classifica o resultado.  
2. **Calculadora de Porcentagem** – Calcula percentuais, descontos e acréscimos.  
3. **Calculadora de Juros Simples** – Calcula juros simples e montante final.

O site é **responsivo, moderno e fácil de usar**, ideal para estudantes, profissionais e qualquer pessoa que precise de cálculos rápidos sem instalar programas.
